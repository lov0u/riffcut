## 一条教训

从字标里抠 R 标时混进了字母 `i` 的黑色竖笔画和一条 1px 横线。试过三种修法
（饱和度硬阈值、邻域密度、纵向窗口密度）都不干净 —— 最后用的是用户单独给的
3D R 标（`04d6d39f...jpeg`），不是从字标切的。以后要 R 标就用 01 目录里
`R标-独立-*` 那两张。
