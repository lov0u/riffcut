新建技能
创建后会自动生成一份 SKILL.md，中间编辑区可以直接改正文、分类和启停，改完点「保存」。也可以导入现成的 SKILL.md。
导入 SKILL.md
填单个 SKILL.md 导入一个；填文件夹 会一次性导入里面所有 SKILL.md（含子目录），正好用来加你给的默认技能包；填 zip 恢复之前导出的备份。
路径可直接粘贴，或按 ⌘V。
导入只把技能写进软件自己的技能库，不会改动原文件。
扫描本机已安装技能
只读扫描 WorkBuddy / CodeBuddy / Claude Code 等智能体装在电脑上的 SKILL.md，按真实路径去重后勾选，一键添加进软件技能库。不会改动、不会删除任何外部文件。
