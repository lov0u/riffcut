# RiffCut 影创 · 隐私政策

版本 2026.11.20-1

> 权利主体：**青网（CyanWeb）**　联系邮箱：**China@cyanweb.cn**　生效日期：2026 年 11 月 20 日

本软件的设计原则是**本地优先、最少记录、不遥测**。本政策如实说明：软件在本机记录什么、什么情况下数据会离开你的电脑、你如何控制这些数据。

---

## 1. 我们不收集什么

1.1 本软件**不开设账号、不要求注册、不内置遥测、不自动联网上传**。权利主体**无法看到**你的素材、成片、对话、字幕、密钥或日志。

1.2 本软件**不采集**：通讯录、短信、邮件、屏幕内容、键盘记录、浏览器历史、定位、相机（除你主动使用拍摄功能时）、麦克风（除你主动使用录制音色时）、以及你设备上的其它无关文件。

1.3 本软件**不含**广告 SDK、行为分析 SDK、崩溃上报 SDK、推送 SDK。

1.4 权利主体**不会**把你的数据用于训练模型、出售给第三方、或用于任何商业目的。

---

## 2. 本机记录哪些数据

全部保存在你的用户数据目录内（默认 `~/Library/Application Support/RiffCut影创/`）：

| 数据 | 位置 | 用途 | 是否必需 |
|---|---|---|---|
| 素材文件路径、时长、分辨率、缩略图、画面分析索引 | `客户/<客户>/` | 扫描、挑镜头、剪辑 | 是 |
| 对话记录、创作方案、需求澄清 | `配置/对话.json` | 继续创作、方案确认 | 是 |
| 模型配置与 **API 密钥** | `配置/模型.json` | 调用你配置的模型服务 | 是 |
| 设置、任务队列、调用量统计、历史 | `配置/` | 功能运行与用量查看 | 是 |
| 成片、图片、配音、工程版本、品牌套件 | `客户/<客户>/` | 交付与按客户隔离 | 是 |
| 授权同意记录 | `配置/授权同意.json` | 记录你同意的协议版本与时间 | 是 |
| 运行日志 | `日志/` | 排障、复现问题 | 是 |

2.2 上述数据**全部保存在本机**，软件不自动上传，权利主体无法访问。

2.3 你可以**随时删除**上述任何文件。删除后对应功能可能不可用，但不影响软件其它部分。

## 3. 数据离开本机的情形

**只有下列情形，数据才会离开你的电脑，且全部由你的主动操作触发：**

3.1 **调用 AI 模型服务**：你发起对话、生成文案、生成图片/视频、语音合成时，相关提示词与素材会发送至**你自己配置的**服务商。发送内容、留存时长、使用方式适用**该服务商的隐私政策**。

3.2 **联网检索**：你使用热点雷达、素材搜索等功能时，检索关键词会发送至相应服务。

3.3 **打开外部链接**：你点击软件内的外部链接时，系统浏览器会打开该网址。

3.4 **你主动提供**：你通过邮件、Issue、群聊等方式主动把文件发给权利主体（例如寻求支持）时，我们才会看到这些内容。

3.5 **软件更新检查**（若启用）：仅发送版本号，不含任何个人数据。

**除上述情形外，本软件不会主动联网。**

---

## 4. 你的控制权

4.1 **查看**：所有数据都在本机文件系统中，你可以随时用 Finder 打开查看。

4.2 **删除**：直接删除对应文件即可。软件不设「云端备份」，删除即彻底删除。

4.3 **导出**：工程、成片、对话记录均为标准文件格式，可自行复制迁移。

4.4 **断网使用**：本软件的核心功能（素材管理、剪辑、出片）可完全离线使用。AI 功能需要联网，但你可以选择不配置模型。

4.5 **密钥管理**：API 密钥以明文存储在本机配置文件中（便于你自行查看与更换）。**建议**：不要在共享电脑上使用，或使用后及时清除。

## 5. 儿童隐私

5.1 本软件**不面向 14 周岁以下儿童**设计，也不会有意收集儿童信息。

5.2 若你使用本软件处理含儿童肖像的素材，须取得其**监护人明确同意**，并遵守《中华人民共和国未成年人保护法》相关规定。

## 6. 数据安全

6.1 本软件采取的技术措施：数据仅存本机、不设远程访问、不内置后门、不自动上传。

6.2 你须自行采取的防护措施：磁盘加密（FileVault）、开机密码、备份、离职交接时清理客户资料。

6.3 **本软件无法防范**：设备丢失、系统被入侵、你主动泄露密钥、你把文件发给了他人。上述情形导致的损失由你承担。

---

7.1 本软件包含的开源组件**不会**收集或上传你的数据。各组件的许可证见 `NOTICE.md`。

7.2 你自行配置的第三方模型服务**不属于**本软件的组件，其数据处理行为适用其自身政策。
