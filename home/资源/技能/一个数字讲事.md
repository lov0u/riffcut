# 一个数字讲事

## 顺序是结论在前，不是数字在前

看到「今年营收 1200 万」就把它做成大号数字滚动，是数据片最常见的做法，也是最容易白做的：
观众看到一个滚动的 1200 万，心里那句话是「所以呢」。

正确的顺序只有五步，少一步观众就不买单：

1. **一句话结论**：先说结果。「三季度收入翻了一倍」——这句话要先出现。
2. **画面证明**：图、柱、线、数字滚动，都放这一步。它是证据，不是开场。
3. **跟什么比**：翻一倍是跟去年比、跟行业比、还是跟目标比？不写清楚，数字没有意义。
4. **所以意味着什么**：对他、对客户、对行业，一句话。
5. **要做什么**：投、买、等、还是换个方式做。

## 一个图只讲一件事

一张图同时讲「增长快」和「成本也高」，观众两个都记不住。
要讲两件事就做两张图，宁可多切一个镜头。

- 峰、谷、拐点必须标出来，不标观众不知道该看哪。
  （流影的做法：subtitle_style 写一条短标注，或者 image_text 叠在图上）
- 目标线、行业均值线要画出来，让「高」有个参照物。
- 想让观众注意某一段时间，就那一段提亮、其余压暗，别靠箭头。

## 数字要能核

- 画面上的每个数字都要能说出来源。说不出来源就别放。
- 「增长 42%」必须带比较对象（跟去年同期 / 跟行业均值 / 跟年初目标）。
- 不要为了让数字好看去凑口径：换了口径就是另一个数。

## 什么时候别这么做

不是所有片子都适合讲数据。一个 20 秒的品牌氛围片里塞三个柱状图，观感会立刻变汇报片。
只有需求里真的出现「业绩 / 增长 / 数据 / 报表 / 汇报 / 战报」这类词，才走这套。
