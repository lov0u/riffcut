# 调色

- 先问「要不要调」，再问「调成什么」。素材本身光比正常、颜色干净，就别调——
  调色是修正或定调，不是必备步骤。调过头的片子一眼假，比不调更糟。
- 要调的两个真理由：同一场戏几段素材颜色不统一（换机位、换时间拍）；
  整条片子要一个统一的情绪底色（冷=疏离/悬疑，暖=生活/亲昵）。
- 可选影调（写进分镜 look 字段）：电影 / 胶片 / 人像 / 黑白 / 冷调 / 暖调 /
  青橙 / 褪色 / 高反差。拿不准先想"这条片子该热还是该冷"，再在里面挑一个。
- 全片只用一种影调。一场戏里两种来回切，观众只会觉得你没调明白。
- 要淡一点写 look_strength（0~1）。半强度是拿原画面混回去，不是把参数调小，
  所以任何影调都能平滑减弱。
- 黑白不是"没颜色"，是另一种语言：适合回忆、证据、压迫感。整条黑白要有理由，
  只把某一段黑白通常是"这段是过去/是想象"。
- 人脸是最先被调坏的地方。人像/暖调会保护肤色，冷调和青橙会把肤色推向绿或橙；
  人物特写多的片子慎用青橙。
- 换影调会重渲那一段，没换的直接用缓存——所以先定影调再逐段微调，别反复改。
