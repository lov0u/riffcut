# 字幕与配音

- **subtitle（逐句字幕，做字幕就用它）**：先把音频按静音切成「一句一段」，逐段离线识别，每句带真实起止时间。整片识别只会给一整段文字，一条字幕盖全片，跟口型对不上。它给的是能直接烧的 .srt。
- transcribe_media：把整片说话声转成一段文字，够用来当文案/口播稿，**不是字幕**。片中没有说话声时返回 0 句，是正常结果，不是模型没装。
- **subtitle_style（样式，短视频必用）**：把 .srt 转成 .ass，出大字、关键词变色、弹入动画。预设 标准 / 大字 / 弹字 / 竖屏 / 标题 / 卡片 / 竖屏卡片 / 卡拉OK / 竖屏卡拉OK / 钩子字 / 编辑字。竖屏预设把字幕抬到画面下方 28% 处，避开平台底部按钮；字号按画面短边算，不写死像素。
- **卡拉OK 预设（口播类优先）**：preset 填「卡拉OK」或「竖屏卡拉OK」，每个字按整句时长平分，念到哪儿哪儿变亮。没有词级时间戳也没关系，中文单字节奏均匀，平分出来观感够用。卡拉OK 模式不再叠关键词上色。
- add_caption：烧字幕进画面。给 .srt 走 force_style 套样式；给 .ass 直接按文件里的样式和动画渲（想有高亮/弹字就必须走 .ass）。
- **一条完整链路**：subtitle 出 .srt → subtitle_style 出 .ass（给关键词）→ add_caption 烧。
- add_music：现场合成配乐，music 留空即可。

**有口播的片子，字幕要按人声对齐**：改成先出配音，再按配音的时间轴做字幕，不要按分镜时长硬分——观众一眼就看出来对不上。
