# 配音音色与情绪

## 音色克隆现状（以 voice_catalog / abilities 实时返回为准）

声音克隆已接入 Ming-3.0（本地 MLX）：选中「我的音色」时，录/导入的样本只当参考音频，试听、分段配音、首页通话都会现合成「用这个音色念新内容」，不会回放你的原录音。「录制我的音色」由界面直接开麦克风录（服务端 ffmpeg 没有麦克风输入）；也可以用「语音备忘录」录好再「导入音色样本」。voice_install / voice_import 会生成提案等用户确认。

## 情绪与语速怎么调（Ming 这类模型才有）

- 能调：情绪（高兴 / 悲伤 / 愤怒 / 恐惧 / 厌恶 / 惊讶 / 自然）、语速（慢速 / 中速 / 快速）、音高（低 / 中 / 高）、音量（小 / 中 / 大）。只有 caps 里带 `emotion` 的模型才显示这些档位。
- 界面：「AI 语音工作室」中栏，选好音色后按组点档位，再试听 / 分段配音。
- 给成片配旁白：add_voiceover 传 text + emotion（+ 可选 speed / pitch），并把 voice_model 设成 ming-tts；没传这些参数时仍走系统预设音色（没有情绪）。
- 系统音色（Ting-Ting 等）没有情绪档，也明确不能克隆本人声音。
- 哪个模型现在能调什么，以 voice_catalog 返回的 param_caps 为准，不要凭记忆。

## 情绪不是档位，是写法

同一个「自然」档，念「夜幕降临，灯光亮起」和念「你说什么？他走了？」出来的东西不一样——**标点、句长、句子之间的停顿，比档位更决定听起来有没有起伏。**

- 长句拆短。一句话超过二十个字，模型会平着念完，没有气口。
- 该停的地方用句号，不要用逗号一路连下去。
- 问句写问号，感叹写感叹号——模型真的会读出来。
- 情绪档只在段落之间换（前半段压低、最后一句抬起来），**不要一句一换**，换不过来反而假。
- 一条片子一种主情绪。旁白第一句是冷的，最后一句还该是冷的，中间才抬。
