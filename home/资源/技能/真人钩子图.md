# 真人钩子图

## 最大的坑不是「不够真」，是「摄影师味」

黄金时刻侧光、背景虚化、居中构图、正面看镜头、衣服板正——这五样一起来，
哪怕纹理词全写对，出来还是「被人摆拍的 AI 图」。模型训练数据里有人物的画面，
绝大多数就是这五种，它默认往那走。

**七样一起往「手机相册」那边推，缺一样它就滑回去：**

| 要什么 | 怎么写 |
|---|---|
| 不看镜头 | 「低头看手机」「看向画外」「正跟镜头外的人说话，说到一半」 |
| 背景是乱的 | 点名两三样：路人虚着、一辆公交从后面过、左边画框边有个垃圾桶 |
| 平光 | 「阴天正午平光，没有黄金时刻，没有轮廓光，均匀漫射」 |
| 业余构图 | 「手持、微微歪、主体偏右半边」 |
| 衣服是穿过的 | 「有点皱的灰连帽衫、洗淡的黑牛仔裤」 |
| 压缩痕迹 | 「能看见 JPEG 压缩痕迹、暗部有噪点、手和手机上有点动态模糊」 |
| 人的不完美 | 「胡茬长得不匀、眼下有暗影、脸略有不对称」 |

负面块要把上面这些反着写一遍：黄金时刻、虚化背景、浅景深、居中、摆拍、
影楼感、杂志封面、正装造型、正面看镜头、网红脸、模特脸。

长度约一百词是**故意的**。别为了短砍掉反摄影师的信号——砍了它就按默认补。

## 五个行业的现成片段

- **健身**：汗湿的灰背心、黑紧身裤，跪在橡胶地板上，后面一副杠铃，头发是湿的，
  正擦汗，疲惫表情｜顶光日光灯有轻微频闪，下巴下一道影。
- **创始人**：皱灰T恤、胡茬没刮，坐一张乱桌前，两台显示器都是代码，半杯咖啡，
  略疲惫地看镜头｜午后窗光从左边来，右脸落暗面。
- **旅行**：亚麻衬衫、浅色牛仔，坐在窄巷里晒白的石墙边，后面是橄榄树，
  鞋是磨过的，手里一张折起来的地图｜午后侧光、暖调、身体拉出长影。
- **理财/职场**：深灰大衣配白T，从写字楼旋转门走出来，一手拿手机，疲惫的半个笑｜
  阴天冷调柔光，没有硬太阳。
- **雪山/户外**：棕色羽绒服、白毛线帽，站在雪场平台看画外，一手松握雪杖，
  微驼｜阴天平光。背景有别的滑雪者和缆车柱。

## 出完字要单独叠

不要让生图模型在画面里写字。出干净图，再用 image_text 压上去（钩子字那档，
自带顶部渐变，白墙上也读得清）。图里出现乱码，整张就废了。
