# 运镜

- 加运镜之前先看素材本身有没有在动。人已经在走、镜头本来就在晃，再加一层推近
  只会打架，看着像手抖。**静止的图、定格、呆照才最需要运镜**。
- 默认是固定。全片每个镜头都在动，观众眼睛没有落点，看两分钟就晕。
- 七种：推近 / 拉远 / 快推 / 左移 / 右移 / 上移 / 下移。
- 推近最常用：注意力越收越紧。用在开场第一个镜头、情绪收紧的那一刻。
- 拉远用来交代环境或收尾，从局部退到全景。
- 快推是一脚踩进画面，冲击强，只在开场三秒或爆点那一下用。
- 左右上下移给静止画面一点纵深，适合空镜、风景、产品全景。
- 幅度默认约 1.25 倍，觉得太猛给 camera_amount 0.5。推太多会糊，
  低分辨率素材尤其明显。
- 运镜不改变段长，字幕、转场、卡点都不用重算。
- 画中画/分屏的段也能加运镜，但小窗里再推会糊成一团，尽量别叠。

## 冲进与甩镜（build 213 起）

**冲进**：前 0.3 秒一口气冲到 2 倍然后**定住**。和「快推」不是一个东西——快推只到 1.25 倍而且边冲边继续推，冲完还在动就晕。冲完停住才有"啪"那一下。

- 用在哪：全片最值钱那一拍——payoff 词、数字落地、反问句、翻盘那一眼。
- 用几次：**最多一两次**。冲三次观众就不知道哪个才是重点。
- 用完要歇：紧跟一个固定镜头，连续冲击等于没有冲击。

**甩镜**：横向甩过去，**只在水平方向糊**（垂直边缘依然清楚）。换场兼换气。

- 用在哪：场景切换、时间跳转、"说到另一个地方"。
- 比叠化有劲：叠化是慢慢告诉你换地方了，甩镜是直接拽过去。
- 别叠加：它本身就是运动，再配一个转场就是两个效果抢一件事。
