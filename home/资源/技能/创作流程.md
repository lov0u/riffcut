# 创作流程（经验与教训，不是规矩）

下面是过去做片子攒下来的经验。**怎么走由你判断**，这里记录的是
「这样做过、结果是这样」，不是「必须这样做」。

## 为什么值得先花两分钟想清楚

用户说「做一条青衣网络的推广视频」，这句话里缺的东西比有的多：
给谁看、要什么结果、最想让人记住哪句、什么不能说、投在哪。

**★ 下面所有例子里的「青衣网络」「官网」「2015 年」都是过去某一单真实案例里的
具体内容，只用来示范手法。2026-11-18 实测踩过这个坑：用户要「RiffCut 影创这个
剪辑软件的介绍片」，模型读完这份技能文件后，稿子里写出来的是
「官网做得像 2015 年，客户第一眼就关掉了」「传统建站：周期三个月、改个按钮要排队」
「扫码加微信，领 3 条免费模板 + 官网诊断报告」—— 它把例子当成了这次的稿子。
**例子是别人的，内容不能抄。这次讲什么，只用这次自己的素材和事实。**

过去直接开工的结果（2026-11 实测）：`generate draft` → 几张图 + kenburns 缓慢推近 →
用户的评价是「这是弄了些什么破玩意，几张图片加个声音就是视频了吗」。

值得注意的一点：**用户自己说他不想被反复问**。他说过「你看着办」「一路做完」的时候，
再拿一轮提问去换他的授权时间，他当场就烦了。所以「要不要问」不是礼节问题，
是成本问题——问一次要花他一次来回。

常见做法是：能自己定的就用行业常识定下来，写成两三行「我按 X/Y/Z 假设」，
然后直接往下做；真正定不了的（客户名、价格、不能说的内容）也先按一个假设做，
做完告诉他「这里我按 X 处理了，要改你说一句」。

## 一、需求里真正影响成片的四件事

不是清单式的五项必问，是这四件一旦搞错整条片子白做：

1. **给谁看** —— 同行、采购、还是刷到的普通人。同一个产品，这三种人要看的画面完全不同。
2. **要什么结果** —— 打电话、加微信、进店、还是只要记住名字。决定结尾怎么收。
3. **最想让人记住哪一句** —— 一句话。他说不出来，就给三个候选让他挑，比自己编强。
4. **投在哪** —— 抖音/视频号 9:16、B站 16:9、还是只发客户看。画幅定了才谈构图。

「有没有不能说的」（价格、客户名、未上线功能、竞品对比）这四条里最容易被忘，
但它是唯一会让片子整个作废的一条。

## 二、调研：回答「凭什么能抓住人」

不是查资料凑字数，是回答三个问题：

- **这个题材，别人怎么开头？** `web_search` 查「<行业> 短视频 开头」「<题材> 爆款」，
  看真实的高播放内容用什么钩子。查不到就说查不到。
- **观众此刻在担心什么？** 采购担心交期和稳定性，老板担心花钱没用，
  终端用户担心不会用。找到那个具体的担心，片子就往那儿打。
- **我们凭什么不一样？** 从客户嘴里挖出来的那句话，比任何形容词都值钱。

调研结果三行写进方案里够了。

## 三、钩子：开头 1.5 秒

不是片头板、不是 logo、不是「大家好」。这 1.5 秒决定他划不划走。

写三个备选，用 `hook_check` 各打一次分（评分细则见「开场与节奏」），
过去实测 7 分以上才够格开片。三种最稳的形态：

- **点名代价**：「官网做得像 2015 年，客户第一眼就关掉了。」（这是青衣网络那单的
  真实句子，只是示范「点名代价」这种形态；**换个产品这句就得换个代价**，
  不能直接搬）
- **反常识**：「询盘少，八成不是流量问题，是落地页在劝退人。」
- **具体处境 + 动作**：「上周有个做五金的老板问我，为什么投了三万广告没电话。」

## 四、文案：骨架 + 每句一个问号

挑一个骨架，别混着用（详见「写稿与文案」）：

| 骨架 | 四步 | 什么时候用 |
|---|---|---|
| PAS | 点名痛点 → 说具体 → 给解法 | 口播、讲道理、大多数推广片 |
| AIDA | 抓注意 → 勾兴趣 → 想要 → 给动作 | 直接卖、投流 |
| BAB | 现在什么样（难）→ 之后什么样（好）→ 中间的桥 | 案例、前后对比 |

**最好用的自检**：每句单独读，读完脑子里有没有升起一个问号。没有就删掉或重写。
四到六句一个循环。

顺序上是文案 → 分镜。反过来（先排画面再硬凑文案）出来的东西，念着就是配图解说。

## 五、画面：这一步的常见坑

到这一步才碰 `make_image` / `make_slideshow` / `generate`。过去实测有效的做法：

- **镜头数 ≥ 文案句数**，一句一个画面。一句配三张图，观众会觉得在灌水。
- **每镜 1.5–3.5 秒**。单镜超过 4 秒观感就是 PPT，除非那一镜本身是长镜头叙事。
- **转场要选过**。全空等于硬切接硬切，硬切也能用，但那是选择，不是默认。
- **关键转折配音效**（`sound_fx`：whoosh / 撞击 / 上升音）。全片一个音效都没有，
  是最明显的业余感来源之一。
- **字幕带样式**（`subtitle_style`：大字 / 关键词变色 / 弹字进场），不是白字一行。
- **全片统一影调**（`color_looks` 或 `style`）。三张图三种色调，一眼假。
- **片头考虑形状揭示**（`reveals`），短视频里最见效果的一招。
- **画面要真的是这句台词说的事**。台词说「工厂改落地页询盘涨 3 倍」，
  配一个人站在车间看手机 —— 结构全对，观众仍然觉得这是随便配的图。
  这是 `film_match` 专门在查的东西。

出片后 `gate` 看技术（死帧、黑场、响度、像素格式），`review` 看画面，
有问题先自己改再交。

## 什么时候不值得走完整套

- **用户明确说「别问了，直接做」** —— 写出你的假设，做完告诉他
- **改已有的片子** —— 文案和结构都定了，只调画面，直接从画面那节开始
- **只是要个粗排给人看** —— `make_slideshow` 够用，它本来就是半成品工具

## 交片前值得自己看一眼的几处

不是清单打勾，是过去被退回来的原因：

- 开场那句话，单独读能让人想往下看吗
- 有没有「我们致力于」「以客户为中心」这类谁都能说的话
- 镜头平均时长是不是超过 3.5 秒了
- 全片有没有一个音效
- 字幕是不是纯白字、有没有样式
- 几个镜头是不是三种色调
- 有没有一张图在缓慢推近超过 4 秒
