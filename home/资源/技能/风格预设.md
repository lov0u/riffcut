# 一条片子定一种气质

**风格不是滤镜，是一整套。** 底色深不深、字压在哪、镜头动不动、接缝硬不硬——
这四样拧在一起才叫气质。拧一半就是"不伦不类"，观众说不上哪里怪，就是觉得不专业。

## 怎么做

1. **先判断片子是干什么的**（不是"是什么题材"，是"要让观众看完干什么"）。
   要他记住一个数字 → 数字讲事的路子；要他相信你 → 纪录片/法庭的路子；
   要他今晚下单 → 投放那一族；要他看懂一个概念 → 讲解那一族。

2. **查风格名**：`style` 工具（不带参数看全部，带 name 看细节）。
   每条都写了"适合什么"和它定的调色/字幕/运镜/转场。

3. **写进方案的 `style` 字段**，就这样：
   ```json
   {"title": "…", "style": "电影感", "shots": [...]}
   ```
   出片时这一整套自动落到分镜上——**你不用再一段段写 look、camera、transition**。

4. **分镜里已经写了的不动。** 一段一个例外是好事，那正是这条片子最该突出的地方。

## 三条硬规矩

- **一条片子一种风格。** 混两种风格的后果不是"丰富"，是"没定下来"。
- **风格定了就别再逐段挑滤镜。** 风格已经包含了调色，逐段再挑会把一套拧好的东西拆散。
- **风格是起点不是终点。** 选完先出草稿看，觉得不对就**换一个风格名重来**，
  别在片段上打补丁——那正是"改了好几版还是不对"的来路。

## 什么时候别用风格

- 用户已经明说"就这个调子别动" → 听用户的，把他的写进每段的 look。
- 片子是系列中的一集，要跟上一集一模一样 → 别换风格，用上一集的风格名。
- 全片只有一个镜头（一条静态图） → 风格用不上，直接调色。

## 挑风格时最容易犯的错

**按"题材"挑而不是按"要观众干什么"挑。**
「这条是讲夜景的」不是判断依据；「这条要让人觉得城市很孤独」才是。
同一个夜景可以配纪录片、可以配惊悚、也可以配预告片——差的是你要什么反应。
