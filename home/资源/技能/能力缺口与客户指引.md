# 能力缺口与补法

| 需求 | 本机状态 | 补法 |
|---|---|---|
| 柔光 / 光影 / 调色 | 已接：十种影调（电影/胶片/人像/黑白/冷调/暖调/青橙/褪色/高反差），可调强度 | 分镜里写 look + look_strength；名字用 color_looks 查 |
| 文生视频 / 图生视频大模型 | 没配这类外部模型 | 「模型管理 → 添加模型」填接口地址、API Key |
| 移动 / 删除 / 整理素材 | 受当前授权档限制 | 「系统设置 → AI 权限」切到「可整理」或「完全托管」 |
| 自动字幕 / 语音转文字 | 片中没说话声时转不出文字 | 可按用户给的文字直接烧字幕 |
| 用我的声音 / 音色克隆 | 已接通（Ming-3.0 真克隆，不回放原声） | voice_catalog / abilities 查实时状态；样本可在工作室直录或「导入音色样本」 |
| 普通旁白 / 配音 | add_voiceover 可用；传 emotion + voice_model=ming-tts 可带情绪 | 系统音色不是用户本人的声音 |
| 调情绪 / 感情 / 语气 | Ming-3.0 支持：高兴/悲伤/愤怒/恐惧/厌恶/惊讶 | 工作室中栏点档位；add_voiceover 传 emotion |
| 转场 / 运镜 / 变速 / 画中画 / 字幕动效 | 已接：转场 50 种、运镜 8 种、变速曲线 5 条、画中画与四种分屏、字幕六档预设含卡拉OK | 分镜里写 transition / camera / speed_curve / layout / inset；字幕走 subtitle_style |

能力接入状态以 capabilities / abilities / voice_catalog / route_status 的实时返回为准。
