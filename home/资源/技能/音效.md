# 音效

- 「电影感」一半来自声音。画面再好，转场没一点风声、撞击没一下闷响，
  看着就像相册。但音效是**点**，不是铺——30 秒的片子三到五处就够，铺满会吵。
- 九种可现场合成（不用下载任何素材包）：冲击 / 轰鸣 / whoosh / 上升音 /
  滴答 / 心跳 / 风声 / 电流 / 啪。
- 最值得加的三处：
  1. **第一个镜头的进场**——people 还没看清画面，先听见一下冲击或 whoosh。
  2. **转场那一帧**——叠化配 whoosh，硬切配啪，闪白配电流。
  3. **爆点前后**——铺两秒上升音，砸下去那一下用冲击。
- 加音效前先听原片有没有原声。本来就有对白/环境声的段，音效要压到 0.5 以下，
  否则盖住人声，观众只听见"咣"。
- 静场不是缺点。该安静的地方加音效反而毁气氛——只有真的觉得"这里太空"才加。
- 音效在成片里的时刻，分镜里写 `at` 是**相对这一段开头**的秒数，
  所以改前面某段长度不用重算后面所有音效。
- 合成的是电子音，不是实录音效。要真实感的撞击/雨声/脚步，得用外部音源。
