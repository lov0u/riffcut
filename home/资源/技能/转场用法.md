# 转场用法

## 一、先决定"要不要"，再决定"用哪个"

**默认硬切。** 观众根本不会注意到硬切，这正是它好的地方。只有要**强调"时间或空间换了"**才用转场。判断法：能不能一句话说出"为什么是它"？说不出就回硬切。

- 有锚点（相似形状、连贯动作、接得上的声音）→ 用动作切
- 没锚点、剧情需要看得见的过渡 → 才用溶接或特效
- **全片不超过 3 种**，七八种花活就像素材拼接器

## 二、什么情绪配什么转场

| 想表达 | 用这些 | 时长 |
|---|---|---|
| 时间流逝、回忆 | 叠化、淡入淡出 | 0.3–0.6s，长了像 PPT |
| 一章结束 | 闪黑（收束）/ 闪白（明亮） | 0.3–0.4s |
| 行进、赶路 | 左推/右推/上推/下推（跟画面动势） | 0.3–0.4s |
| 平滑过渡 | 左滑/右滑/上滑/下滑 | 0.4–0.5s |
| 卡点混剪 | 快淡、闪白（配音效重拍） | 0.2–0.3s |
| 揭晓/覆盖 | 左揭/右揭、圆形开、左盖/右盖 | 0.4–0.5s |
| 粗暴、故障 | 横切片、纵切片、像素化 | 0.3–0.4s |
| 冲击、强调 | 推近、径向 | 0.4–0.5s |
| 温情、医疗、纪实 | 只用叠化、淡入淡出 | 0.4–0.6s |

**温情、纪实、悲伤的素材绝对不用**：横切片、纵向风、像素化、径向。这类效果在情绪片里出现一次，整条的调子就毁了。

## 三、技术上必须知道的三件事

1. **转场会缩短总时长**：两段各 3 秒中间叠化 0.5 秒，成片 5.5 秒；字幕时间轴自动前移。
2. **转场不能比相邻的段还长**（3 秒接两段各 1 秒会自动压到 0.9 秒），那种情况本来就该硬切。
3. **转场期间两段都在动**：素材首尾留余量，别正好切在关键动作那帧 —— 转场会把最精彩的半秒吃掉。

## 四、转场名怎么写

在分镜的 `transition` 字段写中文名。认得出的按它渲，认不出的**一律当硬切**（不会因为错别字就崩）。写"硬切"、"无"、留空都是不加。

常用：淡入淡出、叠化、闪白、闪黑、左推、右滑、左盖、左揭、圆形开、斜切、左擦、像素化、横切片、推近。**完整 50 种和每种的效果描述调 `transitions` 现查**，别凭记忆写。

## 五、交片前自查

- 超过 3 种了吗？每个都能说出"为什么是它"吗？
- 情绪片混进特效转场了吗？
- 长度有没有长到让人觉得"在等它播完"？
