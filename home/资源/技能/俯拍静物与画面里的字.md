# 俯拍静物与画面里的字

## 摆法：照填，别发挥

- **机位**：正俯拍（九成），或第一人称低头看（拍脚、手、桌面）。
- **台面**：深色哑光——炭黑大理石、哑光黑皮、深胡桃木、深灰水泥。永不用白桌。
- **上半幅留空**：上半部必须是大片空台面。高级感就来自这片空。
- **主物一件，偏左或偏右，绝不放正中**；配两件小东西，其中一件被画框切掉一角
- **光**：只从左边或右边来的极暗光，画面大半掉进深阴影，只有一个金属/反光细节带一点高光。
  写「从上方」「均匀打光」就全毁了。
- **负面**：图库感、广告感、专业摄影、明亮布光、纯白背景、构图对称、物体在上半幅。

配 4:5 或 4:3。9:16 竖屏改成「上半幅留空、主物落在下三分之一」。

## 五套氛围，一组只能选一套

- **深暖**（默认）：深胡桃木/炭黑大理石/哑光黑皮｜极暗暖光从一侧｜黄铜或陶瓷一点暖高光。
- **蓝夜**：黑皮车内/碳纤/湿柏油｜极暗青蓝 LED 从一侧，边上露一条蓝霓虹｜冷蓝描边｜负面加「暖色、夕阳、烛光」。
- **天际线**：湿柏油/屋顶石台/金属栏杆｜极暗夜景，上半幅是虚焦高楼灯点（虚焦就是文字区）｜负面加「白天、空天空、室内」。
- **冷调清晨**：浅橡木/米色亚麻/浅灰毛毡｜阴天窗口柔光从一侧｜拉丝钢或一点绿枝｜负面加「暗调、重阴影、钨丝暖光」。
- **黄金时刻**：暖陶土/风化橡木/藤面｜低角度金色侧光斜扫长影｜旧金或蜜色玻璃｜负面加「夜景、冷蓝、LED」。

**同一组换氛围 = 整组散架。**要多套就拆成多组。

## 出歪了先对症状

太亮 → 「极暗」改「非常暗」+「深重阴影占满全画面」。居中了 → 补「偏右/偏左，绝不放正中」
+「刻意不对称构图」（「略微不对称」不生效）。字压到东西上 → 上半幅没留空，第一句改
「上半幅是大片空台面」+ 负面「物体出现在上半幅」。像商品广告 → 负面补「广告感、商业产品照」，
删物件前所有褒义词。光太匀 → 改「从左上」或「从右上」，只一个方向。
像 AI 画的 → 补「轻微横向色差、轻微 JPEG 压缩痕迹、暗部噪点」+「iPhone 15 Pro 后置」。
主物太小 → 补「紧裁」，删「广角」「环境照」。

## 图里要不要写字：五个字是分水岭

1–3 个字、很大很粗：模型偶尔能碰对，想省事可以试一次。4–5 个字：有风险，试就原样加引号。
六个字以上、含数字或标点、字号偏小：一律不要赌——先生成不带字的图，
再用 subtitle / subtitle_style 把字叠上去。
