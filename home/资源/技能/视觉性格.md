# 视觉性格

## 先定一种，再谈画面

一条片子只能有一种视觉性格。两种混着来，观众第一眼说不出哪里不对，
但会觉得「不专业」——因为眼睛一直在切换判断标准。

定性格要说清五件事：**光**（自然还是棚拍、暖还是冷、亮调还是暗调）、
**构图**（居中还是三分、特写还是环境）、**调色**（暖/冷/去饱和/高反差/胶片）、
**主体**（人/物/环境/抽象）、**能量**（静的、动的、沉思的、迸发的）。

## 六种性格，各配什么活

| 性格 | 特征 | 给谁用 |
|---|---|---|
| 编辑型 | 高反差、戏剧光、构图强烈 | 奢侈、时装、高端品牌 |
| 纪实型 | 自然光、抓拍、不摆拍 | 讲真实、讲使命的 |
| 产品型 | 干净、受控、只突出物件 | 电商、功能演示 |
| 生活方式型 | 自然、带向往感、人在场景里 | 消费品牌、健康、日常 |
| 抽象型 | 纹理、形状、微距、气氛 | 科技、创意、概念 |
| 极简型 | 大片留白、主体单一 | 高端、干净 |

## 选图的三层标准

- **技术**：分辨率够（要裁切就 2K 起）、主体实焦、没有压缩伪影、比例适合版面。
- **构图**：有没有一个清楚的视觉落点；背景抢不抢主体；**留不留得出放字的地方**；
  换一个画幅裁了还站不站得住。
- **像不像这一家**：跟前后的画面调子一致；避开图库套路（握手、指着屏幕、
  一屋子人对着笔记本笑）；不用带水印的预览图；商用许可要看清。

## 最容易犯的错

- 前三个镜头暖调、后面突然冷调——**不是风格多变，是没定下来**。
- 一条片子里既有极简留白又有满屏信息——观众不知道该往哪看。
- 用「高级感」当答案。「高级感」不是一个性格，是六个里挑一个挑对了之后的副产品。
## 同一条片子要出竖屏版

不要缩一缩加黑边 —— 横屏缩进竖屏只剩中间一条，观众第一眼看到的是两块黑。
用 `vertical` 工具重排：背景是原片放大裁满 + 高斯模糊压暗（当材质，不抢戏），前景按窗口浮在中间。

- `window` 方形（1080x1080，最稳）/ 四比五（更竖，信息多时用）/ 原比例（只把黑边换成模糊底，不裁内容）/ 满屏（裁满，只在主体本来就在正中间时用）。
- `focus` 决定横向裁哪一块：人物站在画面右边填 0.8，站左边填 0.2。**这一项填错等于把人裁掉一半**，比窗口形状重要。
- `pos` 前景放哪，默认居中。竖屏里字幕会被前景挡：先转竖屏再烧字幕。
