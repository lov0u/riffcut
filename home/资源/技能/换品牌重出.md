# 换品牌重出

客户说「上次那条结构很好，给我们也做一条」——不用重排。重排一遍，分镜数量、
时长、转场、字幕节奏全会变，那已经不是同一条片子了。

## 一句话

`projects action=reskin name=老工程 to=新工程名 customer=新客户`

分镜的 start / duration / transition / look / camera / speed_curve / caption、
口播稿与逐句情绪、画幅帧率、目标时长，全部原样照抄；只换客户、素材、品牌套件。

## 换的与不换的

换：客户（决定产出目录和素材库）、素材文件、品牌套件（logo / 片头 / 片尾 / 主色）。
不换：编排。这是这条路径存在的全部理由。

## 素材要能对上

新客户素材库里没有同名文件时，按「第 N 个视频」顺序对位，池子不够就循环用。
所以**先把新客户的素材扫进来**（`assets action=scan`），再 reskin，否则分镜
指着老客户的文件名，出片时报「找不到素材」。

## 三条硬经验

- 客户认的是**结构**不是素材，所以换素材不影响他认不认；换了结构他就不认了。
- 品牌片头片尾是套件里的资产，出片自动拼上——不要在分镜里自己多插一段「片头」。
- 真要改编排（少一段、换顺序），那就不是 reskin 了：reskin 出一版，
  再用 `generate action=segment` 改那一段。
