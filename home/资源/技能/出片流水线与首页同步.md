# 出片链路与首页同步

「生成视频」在这台机器上不止产出一个 mp4，软件内部还连着这几步：

1. render_clip（单图，source=素材 会自动挑主图）或 make_slideshow（多图）。
   引擎默认 4~5 秒、kenburns、1920×1080、60fps —— **这是兜底值，直接交就是 PPT**。
   做片要自己写 plan.shots，每镜定 duration（1.5–3.5 秒）、transition、look、
   camera、sfx、layout、speed_curve。这些字段全支持，不填就是硬切+无音效+无调色。
   怎么做见「创作流程」。
2. add_music 现场合成配乐，music 留空即可，不需要用户准备音频文件。
3. verify_media 复核文件存在、时长与分辨率。
4. 落库与同步：core.ensure_cover() 生成 `<片名>-封面.jpg`；工程 JSON 写回当前客户；
   首页「最近项目」与底部时间线读的是工程 + 封面，不是 mp4 本身。
   出片工具内部已经串好了这几步。

## 实测踩过的坑

- 整数阶梯 zoompan 在 30fps 下放大运镜会一顿一顿，见「画质与帧率」。
- 外部二次补帧会掉尾帧，一次 filterchain 内一次编码才稳。
- 多次加工会让文件名越叠越长（xxx_配乐_字幕_配音.mp4）。
- 素材目录为空时 render_clip 会报「没有任何图片」。
- 调色、转场、运镜、变速曲线、画中画、字幕样式都已接进分段渲染，
  写进 plan 的 shots 里就生效；具体名字用 color_looks / transitions /
  camera_moves / speed_curve / layouts / subtitle_style 现查。
