# 写稿与文案

**留不住人，多半不是画不好，是每句话都没让人想知道下一句。**

## 一、四种好奇心循环（挑一种照着填）

**破除迷思**：先摆一句大家都信但不对的，摊开机制，以为要反转，再翻一次，给真答案。
> 「都说吞下的口香糖在胃里待七年——真的吗？」→「进去第一秒就被唾液酶分解，但分解不掉。」→「胃酸强到能溶金属，可它的基底完全不怕。」→「那它去哪了？几天后原样出来。」

**What-If**：把日常动作推到极端，让人忍不住看后果。

**升级**：正常 → 更糟 → 最糟，每一级都要比上一级具体。

**反转**：先给结果让人猜原因，最后一句把因果翻过来。

**唯一硬标准**：每句单独读，读完之后脑子里有没有升起一个问号。没有就删或改写。四到六句一个循环，循环之间要有小高潮。

## 二、四种文案骨架（整条怎么起承转合，挑一个套，别混）

| 骨架 | 四步 | 最适合 |
|---|---|---|
| **AIDA** | 抓注意 → 勾兴趣 → 想要 → 给动作 | 卖东西、投流、带货 |
| **PAS** | 点名痛点 → 说具体 → 给解法 | 口播、讲道理、社交平台 |
| **BAB** | 现在什么样（难）→ 之后什么样（好）→ 中间的桥 | 案例、前后对比 |
| **FAB** | 它是什么 → 它能做什么 → 对你意味着什么 | 讲产品、讲功能 |

最短最狠的是 PAS：「每天到家已经九点」→「热口饭二十分钟，吃完只剩刷手机」→「这个三分钟出一碗」。三句话二十秒，不需要第四句。

## 三、只有一条硬规矩：落到具体的东西上

"很累"不是痛点，"到家已经九点，鞋都没脱就坐在门口"才是。
"效果很好"不是卖点，"三个月掉了十二斤"才是。
写完之后逐句问：这句话里的东西，观众能看见吗？看不见就换成能看见的。

## 四、每拍拆两镜，单镜不过四秒

一个"拍"是旁白说五六秒的一小段，至少配两个镜头：A 镜把人和动作放进空间，B 镜切近看细节或后果（东西落下、表情变了、屏幕跳数字）。单镜超四秒观众就开始刷走。相邻两拍的运镜要换：推近 → 横摇 → 上摇 → 静止（当冲击点）。

## 五、声音

旁白 150–175 字/分钟，再快像念稿，再慢会漂。说话时音乐压低、停下回暖，落差本身就是节奏。音效只放画面上看得见原因的那一下。
