# 同一个人反复出现

## 问题出在哪

出图是每次都重新画的。你在第二个镜头里少写了「单眼皮」，它就换一个人；漏了「左手腕有疤」，观众发现不了，但整组图的气质就散了。

**别靠记性重写。** 把长相定成卡，之后每张图都整段带上。

## 怎么做

1. `characters action=save`，`name` 给个名字，`desc` 写到「换个人照着画也能画出同一个人」的程度：
   年龄、脸型、下颌线、眼睛和眉骨、发型发色、肤色、体型、常穿什么、有没有固定配饰或疤痣。
   **一百字以上**，短了模型自己补默认值，补出来的就是那套精致但假的脸。
2. 之后写 prompt 就直接写名字：「阿澈站在天台边上，回头看了一眼」。
   程序会自动把卡里那段长相接在后面，并追加一句「同一个人不许改长相」。
3. 别名一起存（`alias=小澈,澈哥`），换个称呼也认得。

## 三条实际经验

- **卡里写「不变的」，prompt 里写「这一张的」**。发型、脸型、疤痣进卡；今天穿什么、在哪、什么表情、什么光，写在 prompt 里。反过来就乱了。
- **一次只定一个主意**。卡里如果写「有时戴眼镜有时不戴」，模型会平均成一张谁都不像的脸。
- **同一支片子里不换人**。真要换（闪回、几年后），那是两个角色，存两张卡，别在一张卡里写「年轻版/年长版」。

## 注意

本机生图接口只吃文字，不吃参考图。所以卡的写法决定一切——把它当成给一个没见过这个人的画师的brief，不是给自己看的备忘录。
