# 声画分工与旁白

## 一、每一拍先选「这拍归谁」

六选一，选定再写：`原声对白` / `动作声`（耳光、砸杯、推门、枪响）/ `环境音` 或 `配乐` / `沉默` / `旁白`。
先定归属，再动笔。一拍照样能「一个人都不说话」——沉默本身在说话时，旁白闭嘴就是最好的处理。

## 二、旁白只有领到任务才写

六类任务：补前情 / 接因果 / 埋伏笔 / 点破口是心非 / 带过时空 / **闭嘴**。
默认是闭嘴。高能吵架、当众打脸、窒息对视那一拍，全留原声、一句旁白不写。

「七成解说三成原声」只是新手防满铺的参考，不是考核指标。

## 三、六条铁律

1. **起手就摆具体处境+身份反差**。禁「这是一个关于…的故事」「在复杂的局势下」，禁人物简历式开场。
2. **用手头动作和当场后果清零议论腔**。删掉「这意味着」「这是一场…的较量」「内心防线崩塌」「命运的齿轮」。
3. **点名克制**：60 秒内最多 1–2 个核心角色，首句最多一个人名且带出身份；次要角色用关系称呼（她上司、太医、前女友）。
4. **强视觉必须同频**：出现接吻/扇耳光/下跪/晕倒/亮底牌，必须有保留的原声或紧邻旁白正面点破原因；结果落定后直接留白，**不许补一句总结升华**，也不许在收束旁白后再拖一句重复同一结果的原声尾巴。
5. **垫半句、让半句、接半句**：原声出来前旁白只用完整收口短句垫高利害；原声说话时旁白全让开；原声落音后下一块旁白直接接结果。**绝不把原声台词再嚼一遍**，不写破折号，不留半截引子。
6. **一口气顺下来的真人口播呼吸** + 纯器乐配乐（零歌词人声）。原片已有大音量人声插曲，绝不叠外部配乐。

## 四、旁白底下放什么画面

禁「张嘴哑剧」——角色正脸滔滔不绝却被消音，看着像事故。
旁白覆盖段优先切：听者变脸反应 / 动作细节 / 道具特写 / 稳态环境镜；剔除剧烈晃动；同款点头呆看镜全片不超过 2 次。
切入新人物、新场景、情绪骤变，先留 0.5–1 秒把人立住，再让旁白开口，别跟切点抢同一帧。
