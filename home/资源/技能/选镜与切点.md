# 选镜与切点

## 一、入点出点

- **入点能不能再晚半秒**：切在冲突已经摆上台面那刻，不切在人物刚进门、刚坐下、刚开口。
- **出点**：话音落定、巴掌扇完、动作做完之后多停半秒，看对方脸上的反应。
- 片尾最后一拍：结局动作或关键原声落定后，留 1.5–2.5 秒表情/余韵，再干净收尾。
- 切点贴动作收势、原话句尾、自然气口下刀，**别拿固定秒数当尺子硬剁**。

## 二、开场

默认正序，砍掉走路、寒暄、起势，前 3 秒直接落冲突。
只有正序冲突来得太晚，才允许摘一个 ≤2.5 秒的冷开场悬念镜，且必须同时满足：不铺垫也看得懂、不和后文重复同一机位、只抛悬念不泄反转、硬切回正片不跳戏。

## 三、镜头落点（同一句话看谁）

放狠话时，未必看说话人——对面缩紧的瞳孔、攥白的手指往往更有戏。
**反打镜头只要有变脸/心虚/眼眶发红/恍然大悟，就是实打实的戏，不能因为只有半秒当废镜删掉。**

## 四、什么时候不许下刀

- 不许在原片自带的叠化、闪白、转场特效正中间下刀。
- 不许用叠化/闪白/花字去遮自己剪出来的毛病——那是掩盖，不是修复，要微调入出点、恢复连贯运动、合拢相邻段。
- 跨镜头切换至少靠一样东西推着走：画面反差 / 动作顺接 / 声音接力 / 时空跨越。
- 不同场次的镜头只能平行对照或前后呼应，**绝不硬拼成假因果**，绝不提前剧透未发生的结局。

## 五、切得密不密怎么判断

不看固定秒数，看**反打镜头有没有给新东西**。
扫可疑快切：`ffmpeg -i in.mp4 -vf "select='gt(scene,0.35)',showinfo" -an -f null -`（阈值只捞可疑点，闪光灯/叠化/甩镜会误报，要人眼复核）。
- 原片无关碎镜头：整段拿掉。
- 原片相关但太短：顺着原片前后多保留一点真实素材，别硬接。
- 原片有意的快切蒙太奇：每个短镜都给新信息、原速看得清，才保留。

## 六、硬门禁（脚本会拦）

残帧闪帧 ≤0.20 秒 → 拦回；单段最短 0.8 秒；句末呼吸尾垫最多 0.30 秒且绝不跨硬切点；混音真峰值 -1.0 dBTP。
